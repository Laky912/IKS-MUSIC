CONFIGURACIÓN ÚNICA

Activa la búsqueda musical

IKS MUSIC usa la API oficial de YouTube para encontrar videos y reproducirlos con el reproductor oficial.

Cómo conseguirla gratis:
1. Abre Google Cloud Console y crea un proyecto.
2. Activa YouTube Data API v3.
3. En Credenciales, crea una clave de API y pégala aquí.
4. Si restringes la clave por sitio web, permite http://127.0.0.1:8787/*.

La clave se guarda solo en este navegador. No compartas tu clave públicamente.

La cuota gratuita de YouTube API es limitada. Cada búsqueda consume cuota; evita hacer muchas búsquedas repetidas.
